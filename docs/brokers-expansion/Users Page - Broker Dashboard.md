This page should work as the brokerage command center for brokers/admins.

Main goals:

* monitor agent performance  
* track conversations \+ appointments  
* manage teams  
* improve response times \+ conversions  
* route leads intelligently

Implementation:

* KPI cards should be clickable and filter data  
* User rows should show:  
  * leads  
  * response time  
  * appointments  
  * conversion %  
  * AI status  
* Clicking a user opens a right sidebar with:  
  * agent stats  
  * conversations  
  * recent activity  
  * quick actions  
* Team cards should act like mini dashboards  
* Add AI insights:  
  * overdue follow-ups  
  * best performing agents  
  * slow response warnings  
  * conversion trends  
* Add live activity feed:  
  * booked appointments  
  * new replies  
  * reassigned leads  
  * AI recovered leads

**Goal:** Make the page feel like a real-time AI-powered brokerage operating system where brokers can monitor performance, manage teams, track conversions, improve response times, and take action quickly - all from one dashboard.
