# **Layer 1 - Basic Rules**

This is the foundation.

## **Standard Routing Options**

### **Round Robin**

Lead rotates evenly.

Example:

* Lead 1 -> Agent A  
* Lead 2 -> Agent B  
* Lead 3 -> Agent C

Good for fairness.

### **Source-Based Routing**

Examples:

* Zillow leads -> ISA team  
* Open house leads -> assigned hosting agent  
* Luxury website leads -> luxury team  
* Facebook leads -> inside sales

Very important for brokers.

### **Zip Code Routing**

Examples:

* Beverly Hills -> luxury agent  
* Sherman Oaks -> valley team  
* Miami Beach -> condo specialist

This becomes VERY powerful.

### **Price-Based Routing**

Example:

* \<$500k -> junior agents  
* $500k-$2M -> core team  
* $2M+ -> luxury specialists

Huge brokerage feature.

**Lead Type Routing**

Examples:

* Buyer -> buyer specialist  
* Seller -> listing specialist  
* Investor -> investment team  
* Renter -> leasing division

### **Language Routing**

Example:

* Spanish-speaking lead -> Spanish-speaking agent

Very important in large markets.

# **AI Routing Factors**

## **A. Agent Performance History**

AI learns:

* Which agents close Zillow leads best  
* Which agents convert sellers best  
* Which agents respond fastest  
* Which agents book the most appointments  
* Which agents convert luxury leads best

Example:  
 If Agent Sarah converts:

* 18% of Google PPC leads  
   while average is:  
* 7%

AI prioritizes Sarah for those leads.

This becomes:  
 Self-improving routing.

## **B. Speed-to-Lead Intelligence**

AI tracks:

* Avg response time  
* Avg pickup time  
* Avg follow-up consistency

If an agent ignores leads:  
 AI lowers routing priority.

Example:

* Agent A responds in 2 minutes  
* Agent B responds in 3 hours

AI automatically routes more leads to Agent A.

Brokers LOVE this.

## **C. Conversion Intelligence**

AI learns:

* Which agents close buyers fastest  
* Which agents are strongest on listings  
* Which agents perform best by source

Example:

* Agent Mike converts open house leads at 22%  
* Team average \= 8%

AI prioritizes Mike for open house leads.

## **D. Behavioral Matching**

VERY advanced.

AI detects:

* Aggressive lead  
* Slow nurture lead  
* Luxury/high-touch lead  
* First-time buyer  
* Investor mindset  
* Emotional seller  
* Serious timeline

Then routes to matching personalities/styles.

Example:

* Luxury seller -> experienced high-touch agent  
* Fast-moving investor -> aggressive closer  
* Nervous first-time buyer -> patient nurturing agent

This is where AI routing becomes VERY hard to copy.

# **4\. Auto Escalation System**

This is HUGE for brokers.

Most CRMs fail here.

# **Example Workflow**

Lead enters:

* Assigned to Agent A

If:

* No response in 2 mins

AI:

* Sends instant AI reply  
* Push notification  
* Starts countdown

If:

* No human interaction after 5 mins

AI escalates:

* Reassign to backup agent  
   OR  
* Notify ISA team  
   OR  
* Broker alert

This protects expensive leads.

**Escalation Ladder Example**

Minute 0:

* AI responds instantly

Minute 2:

* Push notification to assigned agent

Minute 5:

* SMS reminder to agent

Minute 10:

* Escalate to backup agent

Minute 15:

* Notify team leader

Minute 20:

* AI takeover nurture mode activated

This is VERY valuable for brokerages spending thousands on PPC leads.
