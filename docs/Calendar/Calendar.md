Calendar page should work as a real-time scheduling \+ time management system for agents, teams, and brokers.  
 The goal is to help users stay organized, manage appointments, automate reminders/follow-ups, and connect scheduling directly with leads, conversations, and AI workflows.

How It Should Work:

1. Agent Experience  
    Agents use the calendar to:  
* schedule showings  
* consultations  
* follow-up calls  
* open houses  
* closings  
* personal blocks

Calendar should automatically connect appointments to:

* leads  
* conversations  
* pipeline stage  
* AI follow-up workflows

Agents should quickly:

* create appointments  
* drag/reschedule events  
* send confirmations  
* send reminders  
* open lead conversations  
* call/text directly from appointment

AI Assistance  
 AI should actively help manage the schedule.

Examples:

* suggest best times to schedule  
* remind agents about overdue follow-ups  
* auto-send confirmations/reminders  
* recommend follow-up after meetings  
* identify hot leads needing appointments  
* suggest reschedules for missed appointments

AI Daily Brief should show:

* today's appointments  
* confirmations needed  
* overdue tasks  
* hot leads  
* best response windows

3. Team \+ Broker Usage  
    Brokers/team leaders should monitor:  
* appointments booked  
* agent availability  
* team calendars  
* missed appointments  
* follow-up completion  
* response speed  
* scheduling activity

Should support:

* office calendars  
* team calendars  
* shared scheduling visibility

4. Calendar UX  
    Default to Week View for productivity.

Layout:

* left sidebar \= tasks, reminders, AI insights  
* center \= main calendar  
* right sidebar \= appointment/lead details

Clicking an appointment opens:

* lead info  
* conversation history  
* AI summary  
* quick actions  
* notes  
* reminders

Avoid popup-heavy UX.

5. Automation Integration  
    Appointments should trigger automations automatically.

Examples:

* appointment booked -> confirmation text  
* 24hr before -> reminder  
* after meeting -> follow-up sequence  
* no-show -> re-engagement workflow

6. Live Activity  
    Calendar should feel active/live.

Examples:

* "AI booked showing"  
* "Lead confirmed appointment"  
* "Reminder sent"  
* "Appointment rescheduled"  
* "Follow-up overdue"

Goal:  
 Make the calendar feel like an AI-powered scheduling and productivity operating system that helps agents save time, stay organized, automate repetitive work, and manage appointments/leads more efficiently.
