### **Calling System**

Their built-in calling is very valuable.

Features:

* Click-to-call  
* Call tracking  
* Call recording  
* Call logs  
* Power dialer

Agents like everything staying inside CRM.

WarmChats should focus on:

* AI call summaries  
* Missed-call AI recovery  
* AI detects motivation  
* AI follow-up after calls  
* AI coaching later

How Calls Page Should Work:

1. Main Purpose  
    Help agents:  
* make calls faster  
* track call history  
* follow up efficiently  
* manage missed calls  
* connect calls to leads \+ conversations \+ appointments

Goal:  
 Make WarmChats feel like a full communication hub.

2. Main Layout

Left Sidebar:

* All Calls  
* Missed Calls  
* Voicemails  
* Incoming  
* Outgoing  
* Follow-Up Calls  
* AI Call Tasks

Center:  
 Call history/feed

Each row:

* lead name  
* number  
* call type  
* duration  
* time  
* outcome  
* assigned agent  
* AI summary

Right Sidebar:  
 Lead \+ call details

Includes:

* notes  
* recordings  
* conversation history  
* AI summary  
* next steps  
* quick actions

3. Calling Features

Agents should be able to:

* click-to-call  
* call from inbox  
* call from lead profile  
* use WarmChats number as caller ID  
* transfer calls  
* leave notes  
* tag call outcomes  
* schedule callback

4. AI Features (VERY IMPORTANT)

AI should help heavily.

Examples:

* call summaries  
* action items  
* follow-up suggestions  
* missed call recovery texts  
* detect booking intent  
* detect objections  
* create tasks automatically

Example:  
 "Lead interested in Beverly Hills homes under $1.5M. Wants showing next week."

5. Missed Call Automations

Huge feature for agents.

Example:  
 Lead calls -> no answer

AI instantly sends:  
 "Hey Sarah, sorry we missed your call. This is Joseph from Modern Realty - how can I help?"

This alone is huge value.

6. Call Outcomes

After calls:  
 Agent or AI selects:

* No Answer  
* Left Voicemail  
* Interested  
* Hot Lead  
* Appointment Set  
* Follow-Up Needed  
* Not Interested

This should automatically update lead stage \+ AI workflows.

7. Call Queue / Power Dialer (Future)

For scaling teams:

* call queue  
* power dialer  
* round robin  
* ISA workflows  
* broker visibility

8. Important UX Direction

Do NOT make calling separate from leads.

Everything should connect:  
 Calls ↔ Inbox ↔ Leads ↔ Calendar ↔ AI ↔ Automations

Example:  
 Call booked showing  
 -> appointment created automatically  
 -> reminder workflow starts

Goal:  
 Make Calls feel like an AI-powered calling workspace that helps agents communicate faster, recover missed opportunities, automate follow-up, and convert more conversations into appointments.
